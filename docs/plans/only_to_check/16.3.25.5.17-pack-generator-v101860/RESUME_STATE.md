Architectural rules:

1. The public launcher embeds only generator modules; runtime/system code stays
   canonical in the selected Jaźń source root.
2. Active generator source filenames are version-neutral. Retired sources are
   archived unchanged and are never imported.
3. Mutable wheelhouses live below host `workspace_runtime/local_resources`, not
   below tracked `latka_jazn/local_resources`.
4. A native runner may resolve and author a lock. A foreign runner may only
   replay an existing complete SHA-256 lock with no dependency resolution.
5. Locked replay uses `--require-hashes --no-deps --only-binary=:all:` and full
   target selectors. Input and generated lock bytes must be identical UTF-8/LF.
6. Linux x64 has a glibc 2.17 minimum while accepting compatible older
   manylinux wheel tags. Musl, ARM and macOS remain fail-closed.
7. The launcher uses raw Base85 instead of zlib so generated bytes do not depend
   on the Python/zlib platform build.
8. Only `latka_jazn.tools.release_metadata_sync` may generate
   `PACKAGE_INTEGRITY_MANIFEST.json` and `SOURCE_PROVENANCE.json`.
