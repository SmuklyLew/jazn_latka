## Intent

Rename **Odbiór lokalny** to **TPA — Testy przepuszczania aktualizacji**.
The existing 22 cases (10 shared + 12 migration gates) remain independent
manual acceptance records. Their `manual_results.json` history is unchanged.

## Implemented in this source checkpoint

- `tpa_runner.py`: asynchronously runs **three allowlisted isolated pytest
  regression subchecks**, not all 22 full acceptance scenarios. The allowlist:
  `smoke-isolation`, `config-persistence`, `ui-accessibility`.
- Qt offers **selected safe subcheck / all safe subchecks / cancel**, capped
  output, 120-second deadline and exclusive local JSON evidence under the
  operator state root. A non-allowlisted case is **manual only / BLOCKED**.
- Every automatic result is explicitly an **automatic subcheck**, not full
  acceptance. It cannot mutate the manual PASS, FAIL or archived history.
- Subprocess arguments are literal, no shell; temporary runtime/console/MEMORY
  context is stripped and replaced with isolated values. No ownership of any
  existing runtime PID, service or port is inferred.
- Navigation uses TPA; older studio launchers say **archiwalne/do przeglądu**
  and remain available without being claimed as fully migrated.
- Workbench purple mode has a subdued terminal-inspired palette, fine borders
  and a gradient top bar. No wallpaper or original third-party artwork is
  embedded. Keyboard collapsing (Ctrl+B/Ctrl+J) remains.
- Pulpit and Usługi i procesy use the **same last-observed evidence**, making
  'Pracuje', 'Zatrzymane', errors and unverified readiness distinct.
- Settings can fill only **empty** executable fields from discovery; it does
  not save values or start a daemon. The color palette dialog is preserved.
- Diagnostics preserve operator-facing events, errors and technical logs.
  The existing redacted rotating `errors_jazn_studio.log` remains canonical.

## Deliberately not implemented / gates still OPEN

1. A complete automated runner for **all 22** acceptance cases is not safe
   without distinct temporary daemon instances, approved model access and
   real Windows-specific acceptance. No fabricated PASS for these cases.
2. The twelve legacy studios are **not** replaced by fully native Qt workflow
   pages. Keep `STUDIO_MIGRATION.md` as the parity matrix. In particular,
   Configuration Studio's advanced preview, backup/restore and dirty-state
   semantics remain to be migrated.
3. Automated truth binding of manual evidence SHA/signatures and independent
   EXE/AV adjudication remain OPEN.
4. Persistence of *every raw developer line* is not provided: event logs,
   diagnostic export and bounded/redacted TPA evidence are independent. Never
   persist private chat, raw memory, full inherited environment or tokens.
5. Live daemon, Ollama two-turn, ChatGPT MCP acceptance and all twelve manual
   migration gates remain **NOT RUN** on this host.
6. Source compilation, deterministic pytest, Pyright, integrity/manifest sync,
   CI and GUI visual acceptance must be measured separately. This document
   is not evidence of their success.
