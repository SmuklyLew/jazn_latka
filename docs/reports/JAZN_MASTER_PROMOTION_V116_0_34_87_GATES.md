## CI failure root cause

The previous .86 source updated `PACKAGE_VERSION` but left the two
separately versioned contracts at .85. As a result:

- `latka_jazn/resources/startup_contract.json` did not agree with the runtime.
- `deploy/chatgpt_mcp/deployment.contract.json` carried an outdated full
  runtime version.
- GitHub Actions `persistent-runtime-e2e`, `release-hardening` and
  `powershell-terminal-regressions` asserted the mismatch.

This patch aligns those contracts with the canonical version .87 rather than
relaxing any release checks. Package metadata must be generated by
`latka_jazn.tools.release_metadata_sync`, never hand-authored.
