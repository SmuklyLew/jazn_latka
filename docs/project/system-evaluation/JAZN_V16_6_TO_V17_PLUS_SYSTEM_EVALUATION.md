## Dlaczego rozdzielono indeks od pełnego snapshotu

Pełny audyt zawiera literalne identyfikatory historycznych źródeł pamięci i dawnych artefaktów. Są one częścią opisu provenance audytu, a nie numerami bieżącej wersji systemu. Jednorazowy current-line/v90 audit skanuje śledzone pliki tekstowe pod kątem dawnych tokenów wersji, dlatego pełny, niezmieniony materiał źródłowy jest przechowywany jako snapshot, a ten `.md` pozostaje aktualnym indeksem semantycznym.

Rozdzielenie nie zmienia treści snapshotu ani jego statusu. Dokument nadal nie jest dowodem aktywnego runtime, implementacji planu ani świadomości fenomenalnej.
