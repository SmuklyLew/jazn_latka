# Project-wide documents

Dokumenty w tym katalogu obowiązują przekrojowo w całym projekcie albo stanowią wspólny audyt/reference dla wielu release'ów.

- `PROJECT_ASSUMPTIONS_AND_SCIENTIFIC_BOUNDARIES.md` — kanoniczny kontrakt pojęć i granic naukowych;
- `PLAN_COHERENCE_AUDIT_2026-08-30.md` — audyt spójności planów;
- `system-evaluation/` — przekrojowa ocena architektury v16.6 -> v17+; pełny Markdown pozostaje kanoniczną wersją do linkowania i review, a DOCX jest archiwalnym snapshotem dokumentowym.

Historyczne identyfikatory paczek i źródeł przytoczone w system-evaluation są provenance audytu, a nie deklaracją bieżącej wersji runtime. Bieżący current-line audit rozpoznaje tę różnicę kontekstowo zamiast wymuszać zmianę treści dokumentu.

Te dokumenty nie są same w sobie dowodem aktywnego runtime ani wykonania planu.
