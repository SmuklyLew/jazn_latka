# Project-wide documents

Dokumenty w tym katalogu obowiązują przekrojowo w całym projekcie albo stanowią wspólny audyt/reference dla wielu release'ów.

- `PROJECT_ASSUMPTIONS_AND_SCIENTIFIC_BOUNDARIES.md` — kanoniczny kontrakt pojęć i granic naukowych;
- `PLAN_COHERENCE_AUDIT_2026-08-30.md` — audyt spójności planów;
- `system-evaluation/` — przekrojowa ocena architektury v16.6 -> v17+; kanoniczny `.md` jest indeksem referencyjnym, pełny niezmieniony Markdown pozostaje snapshotem, a DOCX jest archiwalnym snapshotem dokumentowym.

Rozdzielenie indeksu od pełnego snapshotu pozwala zachować literalne historyczne identyfikatory źródeł bez mylenia ich przez jednorazowe audyty migracyjne z bieżącą wersją systemu.

Te dokumenty nie są same w sobie dowodem aktywnego runtime ani wykonania planu.
