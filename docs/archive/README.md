# Historical documentation

Ten katalog zawiera dokumenty zakończone, superseded albo zachowane jako dowód historycznego stanu projektu.

- `plans/` — zakończone/superseded plany;
- `roadmaps/` — stare snapshoty roadmap;
- `reports/` — raporty implementacji/release/hardening;
- `reviews/` — historyczne review;
- `patches/` — historyczne artefakty patch;
- `tools/` — historyczne protokoły/audyty narzędziowe;
- `chatgpt_host_legacy/` — legacy instrukcje hosta.

Historia nie ma pierwszeństwa przed bieżącymi `AGENTS*`, kodem, testami, `docs/project/` ani aktywnymi `docs/plans/`.
