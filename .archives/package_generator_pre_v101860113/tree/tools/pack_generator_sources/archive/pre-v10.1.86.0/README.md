# Archived Jaźń Pack Generator sources

This directory preserves the exact tracked generator source files retired by
the 10.1.86.0 rewrite: v8.8, v8.9 and v10.0.1. They are historical reference
material and are not imported by the public launcher or the active test suite.

The active, version-neutral maintained sources live one directory above and
are deterministically embedded into `tools/jazn_pack_generator.py` by
`tools/build_jazn_pack_generator_bundle.py`.
