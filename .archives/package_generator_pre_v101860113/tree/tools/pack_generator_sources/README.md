# Pack Generator source history

The active Jaźń Pack Generator implementation is no longer maintained in this
folder. Starting with generator `10.1.86.0.111`, the small public launcher is
`tools/jazn_pack_generator.py` and the maintained implementation package is
`tools/jazn_pack_generator_app/`.

`tools/pack_generator_sources/archive/` is historical material only. Nothing in
that archive is imported by the active generator or required at runtime.
